# Website Garden Goals

This is a small, sustainable publishing rhythm—not a content quota. The goal is to leave behind a useful record of curiosity and work.

## Weekly

- [ ] Publish one short note: a technical takeaway, design observation, or collection story.
- [ ] Spend 30 minutes improving one existing page, post, or project description.
- [ ] Refresh the **Now** section when my active focus has changed.
- [ ] Capture one original photo, sketch, or screenshot that could make a future post more personal.
- [ ] Save three ideas in an idea inbox so the next post never starts from zero.

## Monthly

- [ ] Publish one substantial article, guide, or project write-up.
- [ ] Add or update one real project—an experiment counts.
- [ ] Curate five things that shaped my month: links, tools, music, design references, books, watches, or die-cast cars.
- [ ] Check that contact information, links, and the latest writing still represent me accurately.

## Quarterly

- [ ] Publish a **Quarter in Review**: what I built, learned, changed my mind about, and want to explore next.
- [ ] Refresh the About and Now sections.
- [ ] Repair broken links and archive stale goals.
- [ ] Add one considered collection or deep-dive: watches, die-cast details, home-theatre, music practice, or a technical topic.
- [ ] Pick one topic for deliberate depth in the next quarter.

## Editorial lens

Before publishing, ask: **Does this reveal something I noticed, learned, made, or cared for?**

The site’s connecting thread is an appreciation for systems, craft, and detail—whether in code, a room, an instrument, or a miniature car.
